# Workflow Repo CA

This repository contains the workflow project for managing and automating tasks.

## Getting Started

Follow the instructions below to set up and run the project.

### Prerequisites

Ensure you have the following installed:

- [Node.js](https://nodejs.org/) (version 16 or higher)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/AndrewMoisa/workflow-repo-ca.git
   cd workflow-repo-ca
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   ```

### Usage

To start the development server:

```bash
npm start
# or
yarn start
```

### Testing

Run tests using:

```bash
# For unit testing:
npm run test:unit
# or
yarn run test:unit

# For e2e testing:
npm run test:e2e
# or
yarn run test:e2e
```
